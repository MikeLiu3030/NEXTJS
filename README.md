# 🚀 Next.js App Router Course - Dashboard Project

Welcome to the starter template for the official Next.js App Router Course! This is a full-stack dashboard application designed to help you master the modern features of Next.js.

For more details, visit the official [Next.js Course Curriculum](https://nextjs.org/learn).

---

## 📝 Project Overview

This project serves as a hands-on learning companion. Through building this dashboard, you will explore core Next.js mechanisms and best practices, including:

* **⚡ React Server Components (RSC)**: Fetching data directly from the database securely on the server side.
* **🛠️ Server Actions**: Handling form submissions and data mutations natively without building traditional API routes.
* **🔍 Dynamic Search & Pagination**: Implementing highly responsive, URL-synced search bars using debounce techniques.
* **♿ Web Accessibility (A11y)**: Enhancing form experiences with explicit ARIA attributes and live regions for screen readers.

## 🛠️ Quick Start Guide

1. **Install Dependencies:** Run `npm install` or `pnpm install`
2. **Start the Development Server:** Run `npm run dev` or `pnpm dev`
3. **Happy Coding:** Open `http://localhost:3000` in your browser and start working through the course!
